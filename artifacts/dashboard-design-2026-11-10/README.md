# PressDock 工作台设计稿

本次交付为独立页面设计原型。正式业务页面、服务和统计模型均未修改。所有数字、标题和来源均为演示数据，不请求真实 CMS，不执行采集、发布或数据库写入。

打开 `index.html` 即可预览；顶栏太阳按钮切换浅色 / 深色，列配置可以开关状态、时间列。其余业务入口只提示预期目标。

## 设计方向

- 产品：帮助新闻编辑快速核对采集进度和 CMS 审核积压。
- 气质：克制、利落、可核对。
- 材质：沿用 PressDock 现有黑白主题、Geist 字体和线性图标，以稿纸分栏建立信息秩序。
- 重点：需处理数字、采集任务状态和新闻标题。
- 细节：桌面统计区以细竖线区分当天本机采集和跨日期 CMS 审核。

## 现有页面审视

现有界面属于轻度模板感，保留主题、字体、功能和区块顺序。

| 位置             | 问题                             | 设计稿处理                                               |
| ---------------- | -------------------------------- | -------------------------------------------------------- |
| 四张统计卡右上角 | 重复装饰图标，与文字语义重叠     | 移除装饰，保留数字、单位和口径                           |
| 四张统计卡       | 数字权重一致，需处理任务不易发现 | 仅需处理数字用语义警示色，其他数字保持中性               |
| 统计卡下方       | 较长口径说明占用一行             | 收入日期旁说明按钮；本机 / 全部保留在相应统计卡中        |
| 最近记录状态列   | 多个实心彩色胶囊抢过标题         | 用状态圆点与文字表达；排队使用空心点，仍保留全部状态文字 |
| 快捷入口         | 再套一整条圆角容器，层级重复     | 改为紧凑文字入口，与列表保持间距                         |

## 九轮处理记录

| 顺序 | 内容                                                                                                        |
| ---- | ----------------------------------------------------------------------------------------------------------- |
| 间距 | 页边 16px，统计间隔 12px，列表行高 56px；1280×720 可展示五条记录及快捷入口                                  |
| 色彩 | 保留黑白中性主题；金棕表示需处理或进行状态，绿表示 CMS 成功，红表示结果异常；深色单独提高文字亮度           |
| 图标 | 统计卡移除重复图标；操作与导航保留 16px 线性图标                                                            |
| 文案 | 保留业务名称，缩短辅助说明，不添加营销副标题或未经验证的趋势                                                |
| 字体 | 沿用 Geist 与系统中文回退；页名 24px，数字 32px，标题 14px，状态与时间 12px，来源等次要信息 11–12px         |
| 布局 | 页头 → 四项统计 → 五条最近采集 → 快捷入口；内容宽度达到 960px 四列，否则两列；列表内容不足 640px 转纵向记录 |
| 细节 | 数字等宽；长标题和长错误省略并保留完整提示；减少胶囊与重复边框；保留清晰焦点轮廓                            |
| 视觉 | 信息本身承载视觉重点，无装饰插画、虚构图表或生成图片                                                        |
| 动效 | 仅 140ms 颜色反馈；遵循系统减少动态效果设置，无循环动画                                                     |

## 预览与检查

- `1280-light.png`：1280×720 浅色桌面稿。
- `1280-dark.png`：1280×720 深色桌面稿。
- `390-light.png`：390px 窄窗完整内容稿；对应 390×844 视窗需要纵向滚动。
- `layout-checks.json`：1440×900、1280×720、960×720、900×720、390×844 的浏览器布局记录，均无横向越界；包含主题、列配置和刷新提示的交互检查。

渲染使用浏览器 screen 媒体和本地字体。PNG 从浏览器打印输出转换，用于视觉审阅。窄窗稿表示桌面缩窄时的布局，不新增 Android 导航范围。

后续实现沿用现有工作台 Hook、真实数据服务、独立列偏好和错误恢复逻辑；本设计稿不替代这些业务实现。此轮只检查原型语法、格式与浏览器布局，没有重复执行应用全量测试或打包。
