# 工作台真实业务概览验收

日期：2026-11-10。

## 实现

- 工作台使用本机当前账号当天正式采集任务，以及 CMS 一级、二级、三级待审核查询的服务端 total；不再读取本地演示文章。
- 当天统计排除开发调试任务，成功仅表示已添加 CMS。需要验证、登录、失败、中断和提交结果未知计入需处理。
- 最近五条记录按更新时间排序，支持来源打开、独立列配置、640px 以下记录卡和当天采集入口；底部合并为三项快捷入口。
- 首次请求失败显示未读取与重试；刷新失败保留旧数据并提示；缺少任何一级数据不显示部分审核合计。
- 复用已有业务服务、类型化 IPC、缓存和采集通知，没有新增后端接口或迁移。

## 界面检查

使用隔离生产构建渲染实际 React 工作台和布局。账号、任务、审核数字及错误均为明确标注的演示数据，业务方法由内存替身提供，未声明 IPC 与外部请求被阻止；未执行线上 CMS 读写、真实采集或发布。

- 1440×900 与 1280×720 为四列概览；1280×720 下页头、四项统计、五条记录和快捷入口完整展示。
- 960px 为两列概览及三列表格；390px 为两列概览及记录卡，页面内部纵向滚动，快捷入口可到达。
- 浅色、深色、长标题和长错误摘要均已检查；记录区与页面均无默认横向溢出。
- 820px 额外检查发现原顶栏面包屑在长账号名旁换行，随后仅为工作台复用了渠道页的窄窗隐藏及截断策略；此尺寸的早期截图不作为最终视觉证据。
- PDF 是浏览器 screen 媒体的验收中间产物，PNG 是对应渲染图。截图中的所有业务数字均为演示。
