# PressDock

跨平台新闻编辑工作空间（News Editorial Workspace），面向渠道素材管理、稿件整理、图片处理与发布流程。桌面端已连接新闻后台登录、素材增删改、图片上传和当前页排序，并提供本地图片处理与可配置的 AI 标题优化；新增内置 WebView 文章采集、持久队列和 CMS 自动添加；原有本地稿件保留演示标识，正式发布状态尚未核验。

## 技术栈

Tauri 2、React 19、TypeScript 6、Vite 8、shadcn/ui（下拉选择使用 Base UI，其余组件使用 Radix）、Dice UI Data Table（Radix / Nova，TanStack Table 9）、Tailwind CSS 4、Jotai、React Router、Lucide、Zod、Rust、Tokio、SQLx 0.9 和 SQLite。实际解析版本以 package-lock.json / src-tauri/Cargo.lock 为准。

- Windows：MSVC C++ 编译工具、Windows SDK、WebView2。
- macOS：Xcode Command Line Tools；Intel 与 Apple Silicon 由对应架构构建。

## 已实现

- 整个工作区的登录保护、当前用户、退出和系统凭据库会话恢复；密码不保存，令牌不进入前端或 localStorage。
- 渠道素材真实筛选、服务端分页、详情、新增、修改、删除、图片上传和拖动排序；列表列顺序对齐 Web，独立双图列显示实际文件大小及解码尺寸，操作列固定，单图失败可重试。
- ArticleId、Url、LandUrl 通过系统浏览器打开，支持链接复制；外链协议限制为 HTTP/HTTPS。
- 本次运行内记住已提交筛选、页码及每页条数，离开页面后返回自动恢复；重置清空条件并保留每页条数。
- 工作台统计与最近文章、真实素材采集、真实文章筛选与编辑、图片预览、发布状态、系统设置。
- 可复用图片处理组件：左侧拖动 / 键盘裁剪及缩放查看，右侧逐字段预设锁定；Rust 编码 JPG / PNG / WebP，严格核对实际尺寸、格式和体积上限，系统另存为且不覆盖已有文件。
- 可折叠桌面导航、移动抽屉布局、Hash 路由、浅色 / 深色 / 跟随系统，主题与导航偏好持久化。
- 类型化 IPC、Rust 应用信息及数据库健康检查、统一 Toast 错误反馈。
- SQLx 迁移、原始素材与草稿分表、历史列表读取、重复启动不覆盖既有稿件。
- 前端与 Rust 测试、ESLint、Prettier、Windows/macOS CI。

## 素材采集与自动添加

桌面端登录后进入“素材导入”，粘贴 `baijiahao.baidu.com` 或 `mbd.baidu.com` 文章链接，点击“开始采集”或按回车。链接先保存为本地任务，入队后可继续输入；一个后台 worker 依次采集、调用后台格式化、执行启用的自动处理，最后直接添加到 CMS。离开页面任务继续，完全退出应用后停止。

输入框下显示标题、状态、操作三列；标题或未获取标题时的 URL 单行显示，超出列宽显示省略号，悬停查看完整内容，点击始终通过系统浏览器打开原文。状态使用颜色区分：已添加到 CMS 为翠绿色，排队、处理中及等待验证或登录为黄色，失败及提交结果待确认为红色，调试完成、取消和中断保留中性色，适配浅色与深色主题。右侧固定操作列默认宽度 280px，支持调整列宽，按钮空间不足时换行；删除、重试、取消、验证继续、打开来源窗口和 CMS 结果核对按钮均按任务状态显示在操作列。默认按当前账号显示当天入队的记录，可选择日期查看历史。跨日完成的任务仍归入队当天。状态先保存后刷新；相同账号、任务模式和保留期内的相同来源链接定位已有记录，重试更新原记录，不再次入队。已添加、调试完成、失败、取消和中断记录可在操作列点击“删除”并确认；删除只清理本地记录及无引用的采集原文，CMS 文章保留。同链接删除后可重新采集并再次提交，提交结果待确认的记录须先核对。

“系统设置 → 采集与 AI 处理”分别配置 AI 判断分类、AI 生成标签、AI 生成摘要、AI 正文整理和自动内容分页，默认依次为关、开、开、关、关，并选择已保存的 AI 模型。普通设置与历史保留天数停止修改 500 毫秒后自动保存，连续修改合并提交；页面显示待保存、正在保存或已保存，失败保留修改并可重试。切换设置标签或离开页面时立即补存有效修改，重新读取设置或新任务入队前等待补存完成，保存失败阻止本次入队。保留天数无效时显示字段错误，暂停该批保存；开发者模式仍独立即时保存。设置在入队时固定，不改变已有任务；不额外填写密钥。摘要对应 `smallText`，关闭时保留后台简介。未选择模型或 AI 失败保留后台结果并显示回退提示；所有 AI 项关闭时不请求 AI。只开内容分页使用原段落本地分页；关闭内容分页仍会采全来源网站后续页。

元数据 AI 请求未填写模型输出上限时默认使用 8192 token，已填写的上限优先；输出额度包含推理 token。Responses 接口因额度耗尽截断时提示增加上限，内容过滤、生成失败或其他未完成状态分别提示实际原因；未完成文本不用于更新元数据，不自动重试。采集 AI 请求仍以 60 秒为限，失败保留后台结果。

正文整理引用原文片段和图片编号并校验覆盖及顺序，沿用 ArticleHarvest 首尾推广/署名清理、图注绑定和最多一次纠正。整理段落目标 40～100 字，分页目标 240 字，短文不超过 280 字时单页，尾页不足 100 字尝试平衡；单组超长允许超页长。输出仍以 `[!--empirenews.page--]` 分隔。整理或分页失败回退后台排版，原始素材不覆盖。

采集窗口属于应用自己的 WebView，不继承日常 Chrome/Edge 登录。正常采集不抢焦点，等待正文 30 秒后仍未就绪会显示来源窗口；完成登录/验证后在操作列点击“验证完成，继续”，应用会带上已登录会话重新打开本任务链接；也可取消本篇。Windows 使用持久数据目录，macOS 14+ 使用固定数据存储标识，更旧版本由 WebKit 回退默认持久存储。来源窗口没有业务 IPC 权限。隐藏窗口的站点兼容性与各平台登录持久化仍需实机核验。

来源最多 30 页，单次 DOM 回调最多 10 MiB，合并原文最多 16 MiB；不完整、缺标题或采集取消时不提交。后续页失败会保留已采内容检查点。分类启用时读取后台真实分类名称，不照搬旧提示词存在冲突的名称表；读取失败保留默认分类 1。

历史保留时间默认永久，可设 1～36500 天，包含启动当天；保存后下次启动清理过期的成功、调试完成、失败、取消记录。未完成、中断和提交结果待确认的任务保留，已有编辑草稿引用的原文不删除。清理不操作 CMS，也不清除来源站登录。

应用重启后原账号的排队任务可以继续；已在采集/AI 阶段的任务标为中断，手动重试，避免重复付费。提交请求发出后超时、取消或应用退出，标为“提交结果待确认”，不会自动重发。请先到 CMS 核对，再用操作列中的核对按钮标记已添加或未添加；标记未添加后仍须手动重试。退出/换号立即停止旧任务，其他账号不会接管它的队列。“已添加到 CMS”只表示后台接受，不等同于正式发布。

## 采集开发者模式

在“系统设置 → 采集与 AI 处理”开启“开发者模式”（该开关即时保存），在主窗口按 F12 打开 DevTools，查看 Console。默认关闭，开发构建和桌面 release 构建均编入 DevTools 支持；F12 只打开，工具窗口自行关闭。采集来源窗口不开放此命令。关闭模式时所有业务窗口禁用页面右键菜单，开启后恢复；该菜单规则立即跟随已保存开关生效。

**仅影响保存后新入队的任务；已有正常任务仍会提交 CMS。** 模式固定在任务快照中，重试不改变模式；关闭设置也不会补交已有调试任务。调试任务仍访问来源站、调用 CMS FormatContent 和分类查询、执行启用的 AI，因此仍需要登录与模型配置，AI 请求可能产生费用。

调试任务保存原文、处理结果和最终 payload，跳过 Article 创建及提交意图，最终显示“调试完成，未提交 CMS”。正常与调试模式分别去重，关闭开发者模式后重新输入调试过的链接可创建正常任务；同模式仍定位已有记录。调试完成记录使用现有历史保留规则。

日志按任务 ID、尝试次数、步骤和时间分组，输出完整业务输入/结果、提示词与模型响应、各页 HTML、校验/回退、缓存复用及最终 payload，失败默认展开打印错误链、JavaScript 堆栈、HTTP 状态和脱敏的业务错误响应，超限会说明正文不完整；不包含认证凭据或请求头。监听挂在工作区，切换页面继续打印，并核对当前账号。日志只在 Console，不新增日志表或 localStorage 存储；状态、原文和处理结果仍按现有规则持久保存。详细行为见[采集开发者模式](docs/harvest-developer-mode.md)。

## 文章管理

“文章管理”分组含优质文章、一级/二级/三级待审核文章，默认进入优质文章。完整迁移各级筛选和服务端分页，默认 50 条，支持 10、20、30、50、100、200、500 条；查询按页面分别恢复，顶部搜索查询文章标题。完整列、列配置、图片懒加载和固定操作列复用现有表格。

仅保留编辑，以及优质文章的“添加到渠道素材”。编辑使用右侧抽屉和 Tiptap，支持三图、标签、分类、摘要、作者、来源及 HTML 正文；元数据单独修改或正文撤销到初始状态时保留原始正文。正文保留分页标记和图注；遇到表格、嵌入内容或未支持样式时保护原文，显示只读预览，仍可修改元数据。转素材使用真实渠道配置及独立的文章 Id / Publishdate 协议，成功不表示正式发布。原“内容编辑”和本地单篇草稿读写已移除，历史 SQLite 数据及工作台/发布只读列表保留。

正文工具栏上传和粘贴截图、图片文件、Base64 图文均复用 CMS 图片上传接口，仅支持 JPG、PNG、WebP，单张最大 20 MiB。网页右键复制的单图同时包含图片文件和远程 HTML 时上传一次并替换地址；整段图文中的远程图片保留原地址。上传期间锁定编辑、保存和关闭，完成后整次插入支持撤销/重做；单张失败保留文字和成功图片并提示单独补贴，纯图片全部失败保留原文及选区。图片上传后仍需保存修改才关联文章，不自动重试或删除已上传文件。

单图粘贴会清理浏览器附带的网页外观样式，保留图片尺寸和段落对齐，避免颜色、字距等无关样式阻止图片上传；图文混排和历史正文继续执行完整的兼容检查。

正文工具栏支持分页助手：点击打开独立弹框，显示页码、字数和逐页预览，正文编辑区保持完整宽度；内容超长时在弹框内滚动，适配窄屏。定位正文会关闭弹框并跳转到对应页。插入分页符会在选区末尾所在顶层内容块之后分页，不拆段、不替换选中文字；列表、引用、代码块整体处理，图片后的图注保持同页，禁止新建空页和连续分页。可删除分页点或与上一页合并，均可整次撤销和重做。浏览长正文时，工具栏自动固定在抽屉标题下方，滚回原位置后恢复。

“自动分页初稿”按本地 240/280/100 字规则生成只读预览，不调用 AI；应用后替换现有分页，可一次撤销恢复。正文变化后旧初稿失效，取消不修改正文；初稿只调整分页标记，保留原段落、图片和格式。关闭按钮、Esc 或点击遮罩均仅关闭助手并丢弃未应用初稿，保留已应用修改；仍需保存修改才写入 CMS。嵌套分页保留预览并暂停分页调整，保护模式仍只读。分页显示和预览操作不改变保存内容，沿用 `[!--empirenews.page--]` 和现有 CMS 保存链路。

工具栏“HTML 源码”可查看当前待保存的完整 HTML，并在弹窗中编辑。应用时执行净化和兼容校验，不支持的内容保留在弹窗中并提示原因；临时图片地址须改用正文粘贴或上传。应用成功后返回富文本正文，可整次撤销和重做，仍需保存修改才写入 CMS。取消或关闭弹窗不改变正文；保护模式仅允许查看和复制源码。

接口契约、状态映射及验收边界详见[文章管理接口说明](docs/cms-articles-api.md)。线上写请求仅核实契约，尚未使用测试数据实写验证。

## 本地图片处理

桌面登录后进入“图片处理”，选择静态 JPG、PNG 或 WebP，设置裁剪、输出宽高、体积上限和格式，点击“处理预览”查看实际编码结果；“确认结果”打开系统另存为，保存成功后才提示完成。取消不会上传图片或改动原图。已有同名文件不覆盖，请另取文件名。

输入最大 20 MiB，解码 / 输出单边最大 16384 像素、总像素最多 2400 万。默认保留源格式和像素尺寸，缩放查看与屏幕 DPI 不改变导出尺寸。JPG / WebP 根据体积搜索质量（最低 60），PNG 优先无损优化，必要时尝试通过色差检查的减色；无法满足体积上限时禁止确认。透明图片转 JPG 合成白底。支持 EXIF 方向与 RGB / 灰度 ICC 转 sRGB；拒绝动画、CMYK 和损坏的色彩配置，统一输出 8 位颜色。详细接口及验收记录见 [图片处理说明](docs/image-processing.md)。

无需登录和 CMS 的隔离交互验收：`npm run image:qa`，打开终端给出的本机地址。它只连接 Rust 测试编码器，明确标注验收，不提供系统另存为，也不改变纯浏览器工作区的认证限制。

## 新闻后台连接

系统设置按“常规设置 / 采集与 AI 处理 / 图片预设 / 服务连接 / AI 模型 / 提示词模板 / 关于应用”拆分为标签，默认打开常规设置。切换标签保留图片预设、AI 模型和提示词模板的未保存表单和操作状态；离开设置页后重新进入默认打开常规设置，AI 配置引导链接可直接打开对应标签。

“系统设置 → 图片预设 → 子渠道图片预设”可分别配置 TitlePic、TitlePic2 的固定宽高（px）、体积上限（KiB）和一种输出格式（JPG、PNG 或 WebP）。宽高须成对填写，各项可留空；点击保存后写入本机 SQLite，同一工作区账号共用，重启保留。清空某个图片字段的预设后也需保存，不根据子渠道名称推断规则。

子渠道选择器完整显示长名称，空间不足时自动换行。选定目标子渠道后，可在“复制来源”中搜索任意渠道下已保存的其他子渠道预设，点击“复制预设”同时替换 TitlePic、TitlePic2 的表单值（含留空项）；检查或修改后点击“保存图片预设”才生效。未保存的修改不作为复制来源。

新增、修改素材时选择图片会打开处理弹框，并应用当前表单渠道、子渠道及对应图片字段的预设；已配置项锁定，未配置项可调整。仅 TitlePic 或 TitlePic2 地址输入框获得焦点时，粘贴图片才触发处理，纯文本照常粘贴。源图片支持静态 JPG、PNG、WebP，最大 20 MiB，输出可转换成预设格式。没有匹配规则时仍可自由处理，读取预设失败须重试。

点击“处理预览”后确认结果，上传成功才回填对应地址；失败保留结果供手动重试。处理及上传期间禁止保存素材、切换渠道或启动另一个图片操作。取消保留原地址，取消回填不能撤销已发出的上传；已上传文件不会自动删除。仍需保存素材才关联图片。手填地址不自动处理，之后修改渠道也不会自动重传图片。

接口固定为 `https://newsadmin.nccontrol.com.cn`，通过 Rust 请求 Login、CurrentUser、Logout、Article、ArticleClass、PromoteChannel 和 PromoteData。首次使用在桌面端输入后台账号密码；保留 PressDock 静态导航，不加载原站动态路由。HTTP 401 或业务码 A0230 要求重新登录，403 只提示无权限；网络失败可重试，不删除已保存会话。

令牌通过 Windows Credential Manager / macOS Keychain 保存，安全存储不可用时明确提示仅本次运行有效。退出时清除内存会话并禁用已保存凭据；应用数据目录中的 `cms-session-disabled` 仅为非秘密的禁用标记。后台退出可能不即时撤销旧令牌，应用不会宣称已完成服务端撤销。

渠道素材支持真实新增、修改、删除和排序，不提供全文抓取或转存本地草稿。摘要取自 SmallText。渠道配置超过 200 条会继续分页；素材总数仅作服务端参考，仅日期筛选时隐藏不可靠总数。下一页返回空列表时保留上一页，避免依据错误总数持续翻页。

渠道页筛选和操作区固定在顶部，分页固定在底部，只有中间列表滚动；横向滚动条位于分页上方，表头与右侧操作列保持可见。窄屏自动换行，详情及编辑弹层独立滚动。

排序必须完整搜索渠道、子渠道和日期，输入与已提交条件一致且当前页至少两条记录。开始后可拖动手柄或使用上移、下移按钮，期间锁定筛选、分页及增删改。只提交当前页全部 ID，每页排序值均从 1 开始；不调整其他页。保存前会重新查询当前页核对 ID 集合，变化时要求刷新。取消还原原顺序，保存失败保留调整结果。

新增和修改表单与 Web 保持相同字段，Channel、Title、TitlePic 必填；修改先读取完整详情并保留其他字段。保存成功刷新当前筛选和页码；删除需要二次确认，删除后空页退回前一页。图片可手填地址，或选择、粘贴后处理并上传；上传先验证实际解码和 MIME，成功只回填地址，保存素材后才关联；取消不会删除已上传文件。写请求不自动重试，超时或连接中断显示“结果未确认，请刷新核对”。

登录回跳与素材筛选保留路由查询参数。未保存的文章与素材表单仅按账号保存在运行内存，同账号在会话失效后重新登录可恢复；显式退出或更换账号清除。离开未保存表单或排序前会确认，失效后重新进入页面时取消排序并重新查询。现有 SQLite 稿件属于共享本地工作区，本次未增加多账号数据库隔离。

筛选仅记住已提交条件；未点击搜索的修改在离开页面后丢弃。显式 URL 查询优先，前进后退同步记忆。筛选记忆在会话失效后同账号登录时保留，显式退出、更换账号或关闭应用后清空。

图片通过 `cms_load_promote_image` 获取，仅允许本次会话文章/素材列表、详情或上传返回过的 HTTPS 图片地址。请求不带后台令牌或 Cookie，最多跟随 3 次 HTTPS 重定向，单图上限 20 MiB、超时 30 秒；图片服务器的 401 不影响登录。前端接近可视区域才加载，最多 4 个并发，同 URL 合并请求，Blob 内存缓存最多 64 MiB。大小按实际读取字节数计算，尺寸从图片解码获取；预览与元信息共用下载数据，图片和元信息不写入 SQLite 或 localStorage。离开页面释放预览 URL，认证状态变化清理图片缓存。

真实联调需在桌面端运行时登录，使用历史筛选 `2345 / 右侧轮播小图_头条_280x124 / 2026-10-21` 检查展示和筛选恢复。新增、修改、删除和排序保存的验收必须先拦截请求，禁止实际修改线上素材；上传协议可使用单张测试图片验证，不保存素材。不要将真实凭据或令牌加入测试、代码或日志。自动化测试使用本地 HTTP 服务器和凭据库替身，不操作真实素材。接口约定见 [渠道素材接口说明](docs/cms-promote-api.md)。

## AI 模型与标题优化

桌面登录后，在“系统设置 → AI 模型”新增提供商，填写唯一标识、显示名称、API 基础地址和协议（OpenAI Chat Completions / Responses），按需输入 API 密钥并保存。基础地址保留服务商给出的完整前缀，例如 `https://gateway.example/v1`；应用在其后追加 `models`、`chat/completions` 或 `responses`，不自动补 `/v1`。允许 HTTPS，本机 localhost / 回环地址允许 HTTP。重定向不会跟随。

提供商下可手填多个模型，也可“获取可用模型”后选择添加。模型 ID、显示名称必填，上下文窗口、输出 token 上限、推理强度可选，未填写的可选参数不发送。上下文窗口用于记录容量，不推断远端能力、不自动截断正文。“测试”使用固定测试文本调用真实模型，返回可用文本后才显示成功。获取列表失败仍可手填。

“网关兼容设置”支持 Chat Completions 的 `max_completion_tokens` / `max_tokens`、system / developer 角色，以及是否发送 `store: false`。Responses 的输出限制使用 `max_output_tokens`。仅在服务商不接受 `store` 时关闭该字段，关闭后响应保存策略由服务商决定。配置组织和兼容选项参考 [deepseek-harness 的提供商配置](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/llm/llm-pi-ai/src/config.ts)，保持提供商、模型与业务调用分离；没有引入其运行时或插件依赖。

在“提示词模板”中编辑内置的“新闻标题优化”，绑定模型并保存。支持新增、复制、删除以及设置一个默认模板；系统指令与用户提示词均可插入 `{{title}}`、`{{content}}`、`{{count}}`、`{{max_length}}`、`{{requirements}}`。默认 5 个候选、每个最多 30 字符，允许 1–10 个和 1–200 字符，按 Unicode 字符计数，标点计入。被模板引用的模型或提供商须先解除引用才能删除；删除默认模板后不会自动换用其他模板。

渠道素材新增/修改（含文章转素材）的 Title 旁有“AI 优化”。点击后弹窗按默认模板生成，发送当前 Title 和 SmallText，不抓取外链。没有默认模板时须先选择；模板尚未绑定模型时提供配置入口，不发送请求。弹窗可临时改模型、数量、字数和补充要求，修改后点击“重新生成”才再次调用，不改写模板。

候选去空、去重并排除超长结果，不截断标题；返回不足时显示实际有效数量。“采用”只更新表单标题并标记未保存，仍需点击“保存草稿”或“保存素材”。关闭、取消、卸载和登录状态变化会取消或丢弃旧结果，不自动保存、不自动重试付费请求。正文不静默截断，输入超过 4 MB 或模型上下文超限会报错；候选与临时参数不保存历史。

配置保存在本机 SQLite，同一工作区所有账号共用；API 密钥只进入系统凭据库，保存失败明确报错，绝不回退明文。密钥输入留空保留已有密钥，前端读取只有配置状态，不回传秘密。AI 鉴权失败不会使 CMS 退出。自动化验证使用本地 HTTP、凭据替身及明确标识的演示数据，不请求真实 AI、不改线上 CMS。

Android 尚未初始化 SDK / 原生工程或生成 APK，当前提供可运行的移动布局；后续见 [Android 计划](docs/android-plan.md)。不要直接将桌面尺寸和原生行为用于 Android。
