# 渠道素材紧凑改版验收

日期：2026-11-06。范围为桌面渠道列表及新增、编辑表单；手机布局与文章转素材默认弹窗保留。

## 实现结果

- 默认列为位置、新闻内容、主图、第二张图片、操作；新闻内容聚合标题、作者、文章编号。常规行高约 73px（含分隔线），配图 80×36px，元信息合并为一行。
- 渠道、子渠道、日期、搜索、重置、当前页条数、刷新、列配置共用工具栏，按可用宽度换行。详情及删除位于更多菜单，标题、图片可打开详情。
- 列表独立滚动，位置、新闻内容和操作固定，表头及分页保持可见。排序保留当前页规则、拖动与移动按钮、取消还原和提交前重新核对。
- 编辑抽屉为 560px，按标题与摘要、配图、目标渠道、来源信息分组；仅中间表单滚动，保存操作固定。
- 原有列偏好存储键和版本不变。未设置的列使用新默认值，显式显隐和列宽优先，“恢复默认”恢复紧凑组合。只存列设置，不存业务正文。

## 浏览器隔离验收

通过 ego-browser 运行真实 React 页面，使用内存 Tauri IPC 替身。页面标注演示数据，所有 CMS / AI 写入均阻断，不使用真实账号或线上素材。宿主与脚本位于 [验收目录](../artifacts/channel-compact-2026-11-06/)，复用此前调研的只读 IPC 替身。

| 视口宽度 | 页面横向溢出 | 列表行高   | 工具栏高度   | 分页可见 |
| -------- | ------------ | ---------- | ------------ | -------- |
| 1440px   | 无           | 73px       | 57px         | 是       |
| 1280px   | 无           | 73px       | 57px         | 是       |
| 1024px   | 无           | 73px       | 97px         | 是       |
| 768px    | 无           | 73px       | 137px        | 是       |
| 390px    | 无           | 原移动列表 | 原移动工具栏 | 是       |

768px 时默认表格宽 636px，在中间列表内横向滚动。滚至右侧后，新闻内容左侧位置及操作列右边缘保持固定；纵向滚动 300px 后，表头仍贴合列表顶部。未引入选中素材常驻面板。

1440、1024、768px 下抽屉实测均为 560px，900px 高视口中保存按钮底边为 884px，无抽屉横向溢出。保存请求被隔离替身拒绝后，表单保留并显示“此操作未执行，不连接 CMS 或 AI”。排序移动后首条变更，筛选及编辑锁定；取消后恢复原顺序。

## 自动化验证与边界

- 全量 Vitest：32 个文件、240 项测试通过（`npm test -- --maxWorkers=2`）。原并发测试与构建同时运行时出现超时，限制测试并发后全部通过，未延长测试超时阈值。
- 新增旧列偏好恢复测试，更新列表、菜单、中文表单和抽屉分组用例，保留排序、删除确认、图片处理上传、草稿和会话恢复回归。
- 手机渠道及共享默认弹窗继续使用原布局；未改 CMS、IPC、Rust 或数据库协议。
- `npm run lint`、`npm run build`、`npm run format:check` 均通过。本次未进行原生窗口、Android 真机或真实 CMS 写入验收。
