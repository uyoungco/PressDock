# 编辑模式焦点验收

日期：2026-11-05。仅验收竖屏，使用一加 5（`c3edb3ba`）。

## 行为

- 素材新增/编辑、设置编辑、文章编辑、AI 标题、HTML 源码和链接弹框打开时，焦点留在弹层容器，不自动激活输入框。
- 保留焦点约束、Tab 导航和手动点击输入；手动激活输入框后正常弹出软键盘。
- Android 关闭 AI 标题后回到优化按钮；关闭图片处理后回到父编辑容器；关闭源码、链接或分页助手后回到正文工具栏，避免再次激活输入区域。
- 用户明确执行正文定位、编辑命令时仍保留原来的焦点和选区行为。
