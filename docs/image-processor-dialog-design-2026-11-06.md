# 图片处理弹框布局设计稿

日期：2026-11-06。本轮交付布局设计稿，等待用户确认后再调整业务组件。图片及参数取自用户提供截图；HTML 不执行处理、上传或素材保存。

后续状态：用户已确认方案，业务组件现已实现，详见[实现与验收记录](image-processor-dialog-qa-2026-11-06.md)。以下保留当时的设计规格与静态验证范围。

## 现状审查

这是布局密度问题，视觉风格沿用 PressDock。本轮按 Unslop 的轻量优化处理，用户要求的无滚动布局为主要调整范围。

- 外层弹框使用 ScrollArea，内部画布同时设置视口高度与最小高度；标题、文件行、画布及操作栏累加后超过可用高度。
- 图片为横幅，原画布高而图片小，上下黑色留白明显。
- 右侧三项锁定参数仍使用禁用输入控件，每项重复锁定说明，空间被不可编辑内容占用。
- 输出尺寸、裁剪及质量的说明间距偏大，形成长表单。
- 处理预览在右栏，确认及取消在整个组件底部，操作分散且底部被外层滚动带走。

## 设计方向

- 产品：帮助新闻编辑按目标渠道的图片规格裁图、压缩，并在确认后上传。
- 性格：精确、紧凑、克制。
- 场景：编辑台上的图片校样；沿用中性色工作区与校样蓝。
- 视觉重点：图片与裁剪选区，界面控件保持安静。
- 标记：以细线裁剪框贯穿原图与结果核对，参数数字统一对齐。

## 布局规格

| 区域       | 常规窗口                            | 较矮窗口（高度 ≤720px） |
| ---------- | ----------------------------------- | ----------------------- |
| 弹框       | 最大宽 1120px、高 640px，随窗口收缩 | 高度为视口减 64px       |
| 标题区     | 64px，标题 18px，渠道上下文 12px    | 56px                    |
| 文件信息行 | 40px                                | 36px                    |
| 工作区     | 左侧自适应，右侧 272px              | 保留双栏，压缩组内间距  |
| 图片工具栏 | 顶部 40px，底部 36px                | 同上                    |
| 主操作栏   | 固定在弹框底部，64px                | 56px                    |
| 普通按钮   | 32px                                | 32px                    |

弹框采用四行网格：标题、文件信息、弹性工作区、底部操作。工作区、画布允许缩小；所有参数和操作实际容纳在弹框中，不能仅隐藏滚动条或裁掉内容。

## 调整内容

1. 间距：控件按 4px 网格排列；设置区分组间距 12px，矮窗口降为 8px。取消组件内重复的圆角大边框。
2. 颜色：沿用中性色；原图保留色彩，选中页签及当前主操作使用校样蓝，放大风险保持低饱和琥珀色。
3. 图标：统一 16px 线性图标；锁定信息只出现一次，避免每一项重复。
4. 文案：保留本地处理、原图保留和上传关联时机；字段说明缩短，必要的风险直接呈现。
5. 字体：标题 18px，主要控件 13px，元信息 11–12px；数字采用等宽数字。
6. 布局：锁定的格式、尺寸、体积上限改为只读键值行。未锁定参数在后续实现中仍使用紧凑输入控件，保持原有编辑能力。
7. 细节：原图尺寸及体积放在结果对照块，画布底边保留缩放控件；裁剪启用状态按当前预设展示。
8. 视觉：图片默认适应可用宽高，以较大的横幅展示取景，减少无意义黑边。设计稿直接显示提供截图中的图片区域，未生成或替换图片内容。
9. 动效：仅保留控件状态反馈，不增加循环动效或进场装饰。

## 交互约定（后续实现）

- 格式、尺寸、体积上限各自判断是否锁定，支持部分锁定。锁定项显示值及锁定标记；未锁定项在同一行显示 32px 控件。
- 格式使用 JPG / JPEG、PNG、WebP 下拉框。尺寸将宽、高并排显示；取消“输出尺寸”后按原图或选区像素输出。体积上限可直接修改，留空表示不设业务体积上限，原有文件大小和像素安全校验保留。
- 未锁定状态的输入行间距为 4px、组间距为 8px，保持相同弹框尺寸和固定底栏。当前 HTML 加 `?editable` 可查看此状态；图片处理及上传仍为设计展示。
- 默认“适应窗口”。切换 100% 或放大后，超出画布的图片通过按住空格拖动平移；画布不显示横纵滚动条。与拖动裁剪框的交互区分。
- 未生成结果时，“处理预览”为主操作，“确认结果”禁用；生成有效结果后可切换处理结果页签，“确认结果”成为主操作。
- 预设约束、体积校验、放大警告、原图保留和确认后上传的业务规则继续保留。
- 错误放在结果状态块内；长错误按需查看完整说明，避免在右栏连续追加段落。上传及处理状态使用同一状态位置。
- 此稿针对截图中的桌面渠道图片处理弹框，不变更 Android 处理布局。
