## 存储设计核对

- D1 的配置行限 1 MiB；密钥分行存认证密文，主密钥在 Worker Secret。单次 Bootstrap 设计用一条 UNION ALL 查询取同一版本，避免重复大配置或聚合超限。
- 写入设计采用 D1 batch + revision/初始化/序号断言，竞争时重新合并本次字段；回执、设备序号、秘密、墓碑与配置在同一事务提交。
- 成功账本只存回执和请求 HMAC，不存正文/密钥；永久保留成功账本与设备高水位，避免长时间离线重发旧操作。
- 本地有效 generation 和待传队列分离；含秘密的大请求以冻结字节认证加密保存，小型解密密钥在系统安全存储。SQLite 无秘密明文；大请求不直接作为一个凭据密码存储。
- 新表与原业务表分开，现有本机偏好、原文、草稿和任务均需保留。实际迁移/失败补偿在步骤 3/4，跨平台和回退实测在步骤 8。

隔离 SQLite 检查证实两份草案语法有效，提交 guard 的 CHECK 能拒绝不满足断言的值，测试事务回滚后 revision 保持为 0；这不代替真实 D1 的并发/回滚验收。
