# Android 文章管理移动端验收

日期：2026-11-05。正式 Android 配置开放优质文章及三级待审核列表、筛选和分页、元数据与富文本编辑、三图上传、分页助手及优质文章转渠道素材。布局仅由 Android 标识启用，桌面继续使用原表格、列配置、抽屉及窄窗口响应式布局。

## 环境与边界

所有网页观察、交互和截图使用 ego-browser。本机 Vite 临时宿主注入带“演示数据 · 本机隔离验收”标识的内存 IPC 替身，包含 65 篇演示文章、演示图片和 AI 结果。浏览器业务标识为 Android 正式配置，以验证文章入口；另用演示构建标识检查导航隐藏和直接访问提示。两者都不连接真实 CMS、AI 或来源网站，没有进行线上写入。

浏览器内存替身仅存于忽略目录 `.tools/articles-qa`，不进入应用或原生演示包。本轮不扩展 Rust 演示文章接口及存储，不新增数据库迁移或 IPC 请求／返回契约，不将文章正文写入 localStorage。未执行前端、Rust、Android 构建，未打包、安装 APK 或提交代码。

## 竖屏布局

按用户要求仅验收竖屏，不安排横屏或桌面浏览器对照。ego 每轮显式设置视口后测量。

| 视口    | 分页助手生成／关闭按钮 | 结果                                     |
| ------- | ---------------------- | ---------------------------------------- |
| 360×640 | y=580，高 44px         | 页面宽 360px，底栏止于 y=640，按钮可命中 |
| 390×844 | y=784，高 44px         | 页面宽 390px，底栏止于 y=844，按钮可命中 |
| 390×400 | y=340，高 44px         | 页面宽 390px，底栏止于 y=400，按钮可命中 |

360×640 卡片列表内容区高 431px，固定分页栏止于 y=632。390×400 列表仍有 191px 内容视口，编辑保存按钮 y=340、高 44px。HTML 源码、链接编辑及分页助手均检查缩短高度后的底栏；助手长内容滚动时背景列表位置不变。初查发现底栏因 0.75rem 内边距与通用 1rem 负边距不匹配而越界 4px，已在文章专用样式中统一并复查。

保存成功反馈移至文章分页栏上方：390×844 时反馈止于 y=748，分页栏从 y=751 开始，“下一页”仍可命中。图片预览及全屏面板均内部滚动，不修改通用 Dialog、Sheet、Input 或 Button 默认布局。截图留在本机 `.tools/articles-qa`。

## 交互结果

- 四类导航正常，一级有作者筛选，二／三级无作者和 editor，努比亚仅优质文章提供；转素材入口仅优质文章显示。默认 50 条，下一页更新路由并回顶部。切换类别后优质文章恢复第二页和 600px 滚动位置。
- 筛选标题输入取消后重新打开仍保留，搜索后才更新查询。卡片更多信息可展开，主图预览可打开；模拟系统返回先关闭预览，列表或外层编辑仍保留。
- 基本信息／正文切换保留标题。源码追加段落应用成功，撤销后恢复；手动插入分页后助手显示两页，合并后恢复一页，没有自动提交。源码输入和富文本继续复用原兼容校验及 HTML 保真机制。
- 分页助手打开时 AI 调用数为 0；手动生成得到初稿，应用后 CMS 修改调用数仍为 0。挂起请求后取消并释放旧结果，没有显示初稿；关闭助手后释放响应也不恢复生成。正文／标题及会话变化的取消沿用原服务与组件逻辑，既有分页测试继续通过。
- 文章保存注入一次失败后保留输入；保留草稿返回，显式继续编辑恢复标题；再次保存成功才清理草稿。存在草稿时打开另一篇先显示处理确认，取消保留原草稿。
- 缺少分页模板时，从助手进入设置先选择“保留草稿并离开”；设置打开分页用途，来源为 `articles/quality`。返回设置首页再返回文章，原查询和标题草稿可显式恢复，没有恢复 AI 请求。
- 转素材打开 AI 优化时不生成，采用候选仅更新 `material-title` 并恢复焦点，转素材提交数仍为 0。选择演示渠道和子渠道后，第一次保存失败保留候选标题，重试成功；使用 `cms_add_article_to_promote`，没有调用普通素材新增接口，文章推荐信息刷新。
- 主图上传注入失败后保留原地址，重新选择文件才重试；成功只回填地址，保存后才关联。编辑内主图预览返回后编辑仍在。
- 保留文章草稿后退出隔离会话并重新登录，文章恢复入口消失。换号清理复用既有 `retainUser`，新增的筛选草稿及滚动位置与编辑缓冲一并清理；相关认证测试通过。重启不恢复运行内存草稿。
- 演示构建标识下文章导航隐藏，直接访问显示“演示版暂不支持文章管理”，文章 IPC 调用数为 0。
