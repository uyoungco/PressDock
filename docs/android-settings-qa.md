# Android 系统设置与 AI 标题优化验收

日期：2026-11-05。本轮实现完整七项设置及渠道素材新增／编辑中的 AI 标题优化。Android 平台标识启用独立页面与全屏编辑，桌面继续使用原有七标签、分栏、居中弹框和首次自动生成。未增加数据库迁移、业务 IPC 请求／返回结构或凭据存储机制。

## 验证环境与边界

所有网页观察、交互和截图均通过 ego-browser。使用本机隔离的 Android／桌面 Vite 预览及明确显示“演示数据 · 本机隔离验收”的内存 IPC 替身；配置、图片预设、草稿和 AI 结果均为演示数据，没有访问真实 CMS、来源网站或 AI 服务。临时宿主、日志和截图位于忽略目录 `.tools/settings-qa`，不进入正式应用。验收结束后已关闭 ego 任务空间和两个临时预览服务。

本轮未构建前端、Rust 或 Android，未打包、安装 APK、提交代码。浏览器模拟的 `pressdock-back` 仅验证前端返回分派；不能证明原生返回事件、ACL 执行、系统凭据库、IME 或设备安全区已经通过验收。

## 设置交互

- 首页提供常规、采集与 AI 处理、图片预设、服务连接、AI 模型、提示词模板、关于应用。无 `tab` 或无效模块回首页；采集和标题配置入口保留对应深链接及用途，返回来源只接受 `import`、`channels`，默认渠道。
- 提供商进入模型列表，再打开提供商／模型全屏表单。修改名称、输入演示密钥后返回，重新编辑仍保留输入；新提供商显示“继续新增提供商”，新增模型和模板显示未保存条目。保存成功后返回列表并清理该条目的内存输入。路由 state 只有条目 ID 和层级，没有表单或密钥。
- 标题模板与分页模板分别编辑名称，往返切换后各自输入保留。模板保存注入一次失败，表单和错误仍在；再次点击保存成功才返回列表。新模板返回列表后可再次进入同一草稿。
- 删除模板打开独立确认框；模拟系统返回先取消确认，编辑页仍在，再次返回才关闭编辑。Base UI 选择浮层的返回也先关闭选择器，不离开分项。
- 图片预设选择目标“演示渠道 B / 演示信息流”，从“演示渠道 A / 演示轮播图”复制。复制只填入表单，没有保存调用；失败后保留 640×360、100KiB、JPEG，手动重试保存成功；第二图留空原样保留。切渠道后子渠道清空。
- 整个设置有未保存输入时，离开显示继续编辑／放弃并离开。继续编辑留在设置，放弃后回渠道。再次进入设置无之前新增草稿。另已验证退出演示会话后设置卸载、密码输入数为 0；重新进入后提供商名称恢复保存值、密钥为空。账号变化同样通过会话边界及账号 key 卸载设置，组件内存不会跨会话复用。
- 常规主题、采集自动保存／失败重试／离页 flush、提供商密钥留空保留、引用删除限制及各用途独立默认项沿用原有业务服务和校验；本轮未修改相应契约。

## 手机 AI 标题优化

- 打开优化框读取配置和显示标题／摘要，生成调用数为 0；修改候选数量、补充要求后仍为 0，点击“生成标题”才产生一次调用。请求仅包含当前 Title、SmallText、模板／模型及临时参数，没有外链采集。
- 采用候选后只回填 `material-title` 并恢复焦点，CMS 新增／修改调用数为 0；仍需点击保存素材。
- 内存替身挂起响应后取消并关闭，可观察到 `ai_cancel`。重新打开后释放旧响应，候选列表不出现。生成过程中改变素材标题也触发取消，旧结果不会显示。
- 注入生成失败后显示错误，没有自动重试；后续生成必须再次手动点击。候选校验、模板／模型选择、数量与字数限制复用现有实现。
- 缺少模型时前往设置，会先触发素材的“保留草稿并离开”。返回渠道显示“恢复本机素材草稿？”；点击继续编辑后保留采用过的标题，优化框未打开，生成调用数没有增加。
- 演示 APK 的真实请求阻断仍位于 `src-tauri/src/ai/client.rs` 的 `android-demo` 分支。本轮浏览器候选来自明确标识的内存替身，不能视为真实模型或原生演示包验收。
