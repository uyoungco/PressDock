# Android 渠道素材弹框验收

验收日期：2026-11-04。使用 ego-browser / Chromium 模拟视口，覆盖浏览器布局与交互，不使用真机。

## 修复行为

- Android 素材详情、修改素材及图片处理弹框使用独立用途标记，横竖屏均铺满视口，清除桌面居中位移及内容缩放动画。
- 详情标题、关闭按钮和编辑入口保持可见，正文独立滚动，长文本换行。
- 渠道图片处理移除 Android 外层重复滚动；参数工作区滚动，底部操作区固定。桌面继续使用原有居中弹框与 ScrollArea。
- 主图及第二张图片关闭子弹框后，保留编辑内容并恢复对应输入框焦点。

## 隔离方式

本机 Vite 验收入口分别注入 Android、桌面构建配置，直接渲染生产渠道组件，页面始终显示“演示数据 · 本机隔离验收”。未修改正式登录入口或认证限制。

素材读取、图片读取、图片处理、上传和草稿操作全部由本页测试替身提供；图片由 Canvas 在内存生成，草稿不落盘。所有素材新增、修改、删除和排序提交均抛出错误，所有原生 IPC 均被禁止并计数。

最终素材写入次数为 0，意外原生 IPC 次数为 0。移动验收的 2 次上传调用分别模拟失败和重试成功，均只返回内存演示结果，未发送 CMS 请求。

已检查以下交互：

- 从详情进入编辑，主图及第二张图片选择、处理预览、取消返回；预览阶段不上传。
- 参数滚动不带动背景列表；图片子弹框连续打开三次，Escape 仅关闭子弹框并恢复对应字段焦点。
- 预设读取失败可重试；演示上传失败保留处理结果，重试只回填对应图片字段；未保存标题始终保留。
- 横屏图片读取失败时，错误及“返回选择图片”按钮可见、可点击。
- 详情正文滚动及连续三次打开关闭，不改变背景列表位置；关闭按钮、Escape、Android 返回事件均正常。
