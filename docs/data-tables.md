# Data Table

渠道素材及工作台、文章管理、发布管理的文章列表统一使用 Dice UI Radix Data Table，列定义和单元格由业务组件提供，数据请求继续经过现有业务服务、类型化 IPC 与 Rust。上游版本及许可证见 [第三方说明](third-party/dice-ui.md)。

## 列配置

点击“列配置”切换列显隐；标题和操作列始终显示，默认字段顺序与原页面一致。拖动表头右边缘调整宽度，支持鼠标和触控；键盘聚焦调整手柄后，左右方向键每次调整 10 像素，Shift 加方向键调整 50 像素，Home 或双击恢复单列默认宽度。“恢复默认”同时重置全部列宽与显隐。

四个页面分别以 `pressdock.table.<channels|dashboard|articles|publish>.v1` 保存设备级界面偏好，仅包含版本、列 ID、显隐和宽度，不保存账号、正文、图片、查询或密钥。读取时忽略未知字段、无效值和未知版本，限制宽度并强制显示必需列。存储不可用时当前界面仍可使用内存状态。

## 业务行为

渠道页保留固定筛选和操作区、固定分页、独立列表滚动、固定表头与右侧操作列。拖拽排序仅作用于当前页，操作规则、失败重试和取消恢复保持不变；排序或保存期间禁用列配置与列宽调整。表格不二次筛选、排序或分页，继续使用 HashRouter 的已提交查询及既有分页边界规则。

排序从左侧手柄开始，整行内容随拖动移动，松手后调整顺序。原生拖放使用整行影像；未启动原生拖放的 WebView 使用指针整行预览，保留原位置占位和已加载图片。轻点、取消或落在表格外不会改变顺序；退出排序、保存或离开页面会清理拖动状态。

文章表格只展示调用方传入的数据；工作台保留最近五篇，文章管理保留标题和状态筛选，发布管理保留待审核范围与演示标识，不新增字段排序、分页或批量操作。隐藏图片列会卸载该列预览并释放其引用，重新显示时仍由现有图片服务按需加载。

共用 DataTable 接受类型化表格实例、`getRowProps`、空状态、`footer` 插槽和 `externalScroll`。渠道页使用外部滚动容器；文章表格由组件提供横向滚动。列定义保持稳定，调整列宽不卸载仍在显示的图片；业务按钮通过当前 Context 状态更新，避免忙碌或排序状态滞后。

数据列使用明确宽度，宽屏剩余空间由操作列之前的装饰性留白吸收，不按比例拉伸数据列；留白不参与列配置或无障碍导航。实际列宽与保存值及定义边界一致，操作列仍位于右侧。

## 验证

`src/test/data-table.test.tsx` 覆盖各页面偏好恢复与隔离、必显列、尺寸边界、键盘及指针操作、损坏存储、存储异常和空状态。渠道写操作测试验证列配置不请求接口、排序及保存期间锁定，以及原有拖放、WebView 指针补偿、取消与保存行为。真实 CMS 写操作只能通过拦截或测试替身验收。

2026-10-24 验收记录：

- 前端 13 个测试文件、93 项测试通过；`lint`、构建及格式检查通过。
- README 规定的 Rust 格式检查、43 项测试及严格 Clippy 检查通过。
- 隔离 Chromium 验收使用明确标注的演示数据与业务服务替身，未连接真实 CMS。渠道一次显示 30 条，横纵滚动时表头与操作列保持固定；标题由 320 拖至 385 像素后表头、单元格对齐，图片加载计数保持 10 次；刷新后列显隐及宽度恢复，排序期间配置与调整手柄均禁用。
- 390 像素移动布局验证触控将标题由 320 调至 350 像素，页面无横向溢出。文章表格宽屏实际列宽与配置一致，多余空间由留白吸收；移动端仅表格横向滚动，空结果提示在视口内可见。
- 四页分别保存配置，文章页面之间互不影响；编辑链接、状态、演示标识及发布管理的待审核范围保持一致。浅色和深色均检查过。

交互检查在隔离浏览器中完成，桌面产物通过 Tauri Release 构建生成 EXE、MSI 和 NSIS；未把浏览器验收视为真实 CMS 写入或原生 WebView 交互验收。
