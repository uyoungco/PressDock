# 手机端设计实施与验收

依据：[已确认的手机端设计稿](mobile-ui-design-2026-11-06.md)。本轮将方案应用到实际 React Android 分支，保留已有桌面工作区、服务调用和类型化 IPC。

## 实施内容

- 顶栏保持 48px，长账号昵称与外观切换移到导航底部。文章标题旁提供原有四个 CMS 类别入口，继续由原路由恢复各类别查询；设置分项的返回交给现有层级处理。
- Android 使用纸白、墨黑、校样蓝的浅深主题。主要触控区统一为 44px，列表采用 16px 页边距、15px 标题与 12px 元信息。主题变量作用于平台根节点，浮层沿用相同配色。
- 渠道保留双图与排序控制，筛选条件集中成一行；编辑直接可达，删除进入更多菜单并继续确认。图片规格仍在详情中保留。
- 文章改为标题、缩略图和元信息组成的连续列表。完整信息、来源及三张图片仍可查看；正文页签保持挂载，工具、分页、源码和保存仍使用现有流程。
- 导入去除重复标题，链接、日期与记录靠近；记录增加来源域名和时间，删除收进菜单。运行、验证、失败、待确认提交等业务状态与动作保留。
- 图片页压缩重复文件信息，画布与参数独立滚动，横竖屏均固定底部操作。实际检查、编码、导出和渠道回填仍调用原图片服务。
- 设置使用单层页头和带用途说明的七项分组列表，保留提供商、模型、模板的编辑层级、草稿与离开拦截。
