## 修复

Android 生产构建面向 Chrome 111，CSS 压缩会把 `translate: none`、
`transform: none` 和 `scale: none` 合并为 `transform: scale(1)`。
基础 Dialog 的独立 `translate` 仍引用 Tailwind 的 `-50%` 变量，导致全屏弹框向左上偏移。

在现有四组全屏规则中同时设置 `--tw-translate-x: 0` 和
`--tw-translate-y: 0`，保留原有定位、变换重置和渠道筛选的方向媒体条件。
普通确认框、删除提示、链接编辑和导航抽屉不扩大重置范围。
本次不修改业务接口、IPC 或数据库。
