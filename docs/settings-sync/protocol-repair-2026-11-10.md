# 配置同步 v2 上报修复与上线验收

日期：2026-11-10。所有客户端统一升级至 v2，不提供旧版写入兼容。

## 原因及修复

正文整理增加共享字段后，客户端已发送 v2，正式云端仍是 v1（revision 18）。v2 操作被永久拒绝并阻塞队列，原来的“手动同步”又禁止处理该状态，单独升级云端无法解除已发生的阻塞。

新增 `protocolMismatch` 展示状态，从持久化队列恢复错误。手动同步先完成 v2 bootstrap 校验和回执查询，再只恢复因版本不匹配暂停的 v2 请求。操作身份、序号、原始字节及加密引用保持不变；其他永久错误和 v1 冻结操作不解锁。后台不会对不兼容服务循环上传。健康检查增加 `schemaVersion`。
